# شروع کار در ۵ دقیقه

۱. **ثبت‌نام**  
   به [سایت دیاراد کلود](https://diarad.2bd.net) بروید و ثبت‌نام کنید.

۲. **ساخت ابرک**  
   از پنل کاربری، گزینه‌ی «ساخت ابرک جدید» را انتخاب کنید.

۳. **اتصال به ابرک**  
   پس از ساخت، اطلاعات SSH به شما نمایش داده می‌شود. با دستور زیر وارد شوید:
   ```bash
   ssh username@ip -p port
```
۴. شروع به کار
ابرک شما آماده است! می‌توانید نرم‌افزارهای خود را نصب کنید.
