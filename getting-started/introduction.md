# دیاراد کلود چیست؟

دیاراد کلود یک پلتفرم ابری آزاد و اشتراکی است که با هدف ارائه‌ی زیرساخت ارزان و قابل اعتماد برای توسعه‌دهندگان ایرانی ساخته شده است.

## ابرک چیست؟
ابرک یک واحد میزبانی سبک و پویاست که برخلاف سرورهای مجازی سنتی، سخت‌افزار را به صورت ثابت بین کاربران تقسیم نمی‌کند، بلکه یک استخر مشترک از منابع ایجاد می‌کند که هر ابرک به اندازه‌ی نیاز لحظه‌ای خود از آن استفاده می‌کند.
